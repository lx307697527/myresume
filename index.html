Private AI · AllyOS

A private AI server that never leaves the office

SGLang · Docker · WSL2 · RTX Pro 6000

Problem

The team wanted AI help, but couldn't send customer and production data to a public cloud.

What I built

A quantized open model on one workstation GPU, served through SGLang in containers, with tiered access designed for Slack agents.

Result

It runs AllyOS's AI coding agent today — 134 pull requests generated without sending a line of code to an outside AI provider. Next: company-wide access through Slack.

AI engineering · AllyOS

An AI coding agent that turns issues into pull requests

Local LLM · GitHub · CI

Problem

A small dev team had more feature requests than hands to build them.

What I built

"Agent Coder", a GitHub account backed by our local model. Assign it an issue and it builds the feature and opens a pull request, inside a branch flow with CI and separate test environments.

Result

Since September 2026 it has opened 134 pull requests, and 129 were merged — a 96% acceptance rate. AllyOS ships to production every two days, and a release batch that fails review rolls back automatically.

Business systems · AllyOS

What I built

Result

4,000+ pull requests merged and 3,300+ issues closed since July 2026. Staff, customers and the website share one system, and incoming customer payments are flagged early through Ramp while QuickBooks stays the books of record.
